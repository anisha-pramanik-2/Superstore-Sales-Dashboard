# Superstore Sales Dashboard

## Overview

This project is an interactive **Power BI Sales Dashboard** built using the **Superstore dataset from Kaggle**. The project focused primarily on **dashboard creation, visualization, interactivity, and business insight generation**.

## What I Implemented

* KPI cards for **Total Sales, Total Profit, Total Orders, and Total Quantity**
* **Sales by Category** analysis
* **Sales by Region** comparison
* **Monthly Sales Trend** visualization
* Interactive **slicers** for Category, City, Ship Mode, and Segment
* **Button-based filter panel** using **Bookmarks and the Selection Pane**
* Business **Insights section** summarizing key findings


## Key Insights

* **Technology** is the top-performing category.
* **West** is the highest revenue-generating region.
* **November** shows the strongest sales performance.


## Tools Used

* **Power BI**
* **Power Query**
* **Bookmarks**
* **Selection Pane**
* **Kaggle Superstore Dataset**
